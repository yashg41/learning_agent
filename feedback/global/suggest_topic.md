# Guidance when suggesting next topics

- Always explain *why* each suggested topic is being proposed — what it unlocks or how it connects to something the learner just practiced.
- Include one "stretch" suggestion alongside the safe picks, especially if the learner is ready to branch into ML / DL / LLM / MLOps.
- When the learner has just mastered a concept, lean the suggestion toward something that uses it, not something unrelated.
- If the learner's primary track isn't Python (e.g., ML or DL), still surface one Python fundamental they haven't covered when relevant — Python gaps slow everything else down.
